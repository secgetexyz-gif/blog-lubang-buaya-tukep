# Jejak Langkah di Lubang Buaya — Jurnal Kunjungan Sejarah

Blog interaktif bergaya jurnal pameran museum (*exhibition journal*) untuk tugas Sejarah Indonesia mengenai kunjungan ke Kompleks Monumen Pancasila Sakti, Lubang Buaya, Jakarta Timur.

## Cara Mengganti Nama Penulis
Buka `index.html`, cari baris `<!-- GANTI NAMA PENULIS DI BAWAH INI JIKA PERLU -->`, lalu ubah teks `Catatan Pelajar Kelas XII` menjadi nama lengkap penulis.

## Cara Publikasi ke GitHub Pages
1. Buat repository baru (Public) di GitHub.
2. Upload `index.html`, `README.md`, dan folder `images/` (berisi 10 foto) ke root repository.
3. Buka **Settings** → **Pages** → pilih Branch `main` dan folder `/ (root)` → klik **Save**.
4. Tunggu 1–2 menit hingga alamat `https://<username>.github.io/<nama-repo>/` aktif.
